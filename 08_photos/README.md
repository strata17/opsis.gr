# Opsis photo library

- `bw/`: graded with the video toolkit's `grade.py` settings (ink #0D1116 to off-white #F5F5F2, tanh contrast curve, unsharp mask, max 2400px wide).

Photos used on the site are copied to `src/assets/photos/` and credited in each piece's `photo.credit`.
